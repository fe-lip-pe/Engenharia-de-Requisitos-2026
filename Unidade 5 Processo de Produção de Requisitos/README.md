## 📌 Sobre o tema

O **Processo de Produção de Requisitos** é o conjunto de atividades utilizadas para descobrir, compreender, documentar e validar as necessidades dos usuários e demais envolvidos em um projeto de software.

Esse processo ajuda a definir o que o sistema deverá fazer e quais condições deverá atender.

## 🎯 Objetivos

- 🔎 Identificar as necessidades dos usuários.
- 📝 Registrar os requisitos de forma clara.
- 🤝 Facilitar a comunicação entre clientes e desenvolvedores.
- ⚙️ Evitar ambiguidades e conflitos.
- ✅ Garantir que os requisitos atendam aos objetivos do projeto.

---

## 🔄 Etapas do Processo de Produção de Requisitos

### 1. 🔍 Levantamento de requisitos

Consiste em coletar informações com os usuários e outras partes interessadas.

**Técnicas utilizadas:**
- Entrevistas.
- Questionários.
- Observação.
- Reuniões.
- Análise de documentos.

### 2. 🧠 Análise de requisitos

Os requisitos coletados são organizados e avaliados para identificar conflitos, inconsistências e necessidades que ainda não foram esclarecidas.

### 3. 📄 Especificação de requisitos

Os requisitos são documentados de maneira clara, organizada e compreensível.

Essa documentação pode incluir descrições, regras de negócio, casos de uso e critérios de aceitação.

### 4. ✅ Validação de requisitos

Verifica se os requisitos representam as necessidades reais dos usuários e se estão completos, consistentes e compreensíveis.

### 5. 🔧 Gerenciamento de requisitos

Acompanha os requisitos ao longo do projeto, controlando mudanças e mantendo a documentação atualizada.

---

## 📝 Tipos de requisitos produzidos

| Tipo | Descrição | Exemplo |
|:---|:---|:---|
| ⚙️ Funcional | Define o que o sistema deve fazer. | Permitir o cadastro de clientes. |
| 🔒 Não funcional | Define critérios de qualidade ou restrições. | Proteger os dados dos clientes. |
| 📋 Regra de negócio | Define condições e regras da organização. | Cada pedido deve possuir um identificador único. |

---

## 💻 Exemplo prático

Imagine a criação de um sistema de vendas pela internet.

**Necessidade do usuário:**
O cliente deseja comprar produtos sem precisar ir até uma loja física.

**Requisitos identificados:**
- O sistema deve permitir a criação de uma conta.
- O sistema deve permitir a consulta de produtos.
- O sistema deve permitir a realização de pedidos.
- Os dados pessoais dos clientes devem ser protegidos.

**Resultado esperado:**
Um sistema que atenda às necessidades dos clientes e facilite o processo de compra.

## ⭐ Importância do processo

- 📉 Reduz erros e retrabalho.
- ⏱️ Evita atrasos no desenvolvimento.
- 🤝 Melhora a comunicação entre os envolvidos.
- 📈 Aumenta a qualidade do software.
- 🎯 Ajuda a manter o projeto alinhado aos objetivos definidos.

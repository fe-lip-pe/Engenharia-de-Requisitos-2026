## 📌 O que é Engenharia de Requisitos?

A **Engenharia de Requisitos** é uma área da Engenharia de Software responsável por identificar, analisar, documentar, validar e gerenciar as necessidades e expectativas dos usuários em relação a um sistema.

Ela estabelece uma base para o desenvolvimento do software, definindo suas funcionalidades, características e restrições.

## 🎯 Objetivos

- 🔎 Identificar as necessidades dos usuários.
- 📝 Definir os requisitos do sistema.
- 🤝 Melhorar a comunicação entre clientes e desenvolvedores.
- 🛠️ Reduzir erros e retrabalho.
- ✅ Garantir que o software atenda aos objetivos do projeto.

---

## ⚙️ Principais características

### 🔍 1. Identificação de necessidades
Busca compreender os problemas que o sistema deverá resolver e as expectativas dos usuários.

### 🧠 2. Análise
Avalia os requisitos identificados, verificando sua viabilidade, consistência e clareza.

### 📄 3. Documentação
Registra os requisitos de forma organizada para orientar o desenvolvimento e os testes.

### ✅ 4. Validação
Confirma se os requisitos representam corretamente as necessidades dos interessados.

### 🔄 5. Gerenciamento
Controla as alterações dos requisitos durante o ciclo de vida do software.

---

## 📝 Tipos de requisitos

| Tipo | Característica | Exemplo |
|:---|:---|:---|
| ⚙️ Funcional | Define o que o sistema deve fazer. | Permitir cadastro de usuários. |
| 🔒 Não funcional | Define qualidade ou restrições. | Garantir segurança dos dados. |
| 📋 Regra de negócio | Define regras da organização. | Impedir pedidos sem produtos cadastrados. |

---

## 🔄 Atividades da Engenharia de Requisitos

1. **Elicitação:** coleta das necessidades dos usuários.
2. **Análise:** organização e avaliação dos requisitos.
3. **Especificação:** documentação dos requisitos.
4. **Validação:** verificação dos requisitos com os interessados.
5. **Gerenciamento:** acompanhamento e controle das mudanças.

---

## 💻 Exemplo prático

Imagine um sistema de biblioteca.

**Necessidade:** facilitar o controle de livros e empréstimos.

**Requisitos funcionais:**
- Cadastrar livros.
- Registrar empréstimos.
- Consultar a disponibilidade de livros.

**Requisitos não funcionais:**
- Proteger os dados dos usuários.
- Apresentar uma interface fácil de utilizar.

**Resultado esperado:** um sistema organizado, confiável e adequado às necessidades da biblioteca.

---

## ⭐ Importância

A Engenharia de Requisitos é fundamental porque:

- 📉 Reduz falhas no desenvolvimento.
- ⏱️ Diminui o retrabalho.
- 💰 Ajuda a evitar custos desnecessários.
- 📈 Melhora a qualidade do software.
- 🎯 Mantém o projeto alinhado às necessidades dos usuários.

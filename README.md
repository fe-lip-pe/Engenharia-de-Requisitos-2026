## 📌 Sobre o projeto

A **Engenharia de Requisitos** é uma área da Engenharia de Software responsável por identificar, analisar, documentar, validar e gerenciar as necessidades dos usuários de um sistema.

Seu principal objetivo é garantir que o software seja desenvolvido de acordo com as necessidades e expectativas dos envolvidos no projeto.

## 🎯 Objetivos

- 🔎 Identificar as necessidades dos usuários.
- 📝 Documentar os requisitos do sistema.
- 🤝 Melhorar a comunicação entre clientes e desenvolvedores.
- 🛠️ Reduzir erros e retrabalho.
- ✅ Garantir que o sistema atenda aos requisitos definidos.

---

## ⚙️ Tipos de requisitos

| Tipo | Descrição | Exemplo |
|:---|:---|:---|
| ⚙️ Funcional | Define o que o sistema deve fazer. | Cadastrar usuários. |
| 🔒 Não funcional | Define critérios de qualidade e restrições. | Garantir a segurança dos dados. |

## 🔄 Etapas da Engenharia de Requisitos

### 1. 🔍 Elicitação
Coleta das necessidades dos usuários por meio de entrevistas, reuniões e questionários.

### 2. 🧠 Análise
Organização dos requisitos e identificação de conflitos, ambiguidades e inconsistências.

### 3. 📄 Especificação
Documentação clara dos requisitos que o sistema deverá atender.

### 4. ✅ Validação
Verificação de que os requisitos representam corretamente as necessidades dos interessados.

### 5. 🔧 Gerenciamento
Acompanhamento e controle das alterações nos requisitos durante o projeto.

---

## 💻 Exemplo prático

Imagine o desenvolvimento de um sistema para uma biblioteca.

**📚 Requisito funcional**
- O sistema deve permitir o cadastro de livros e usuários.

**🔐 Requisito não funcional**
- O sistema deve proteger os dados pessoais dos usuários.

**🎯 Resultado esperado**

Um sistema organizado, seguro e adequado às necessidades da biblioteca.

---

## ⭐ Por que a Engenharia de Requisitos é importante?

- 📉 Reduz falhas no desenvolvimento.
- ⏱️ Evita desperdício de tempo.
- 💰 Ajuda a reduzir custos.
- 📈 Melhora a qualidade do software.
- 🤝 Facilita o entendimento entre os envolvidos.
